# dniWebCraft
**Performance & Conversion Web Developer**

I build fast, clear, and easy-to-use business websites. A website does not need to be complicated to be useful. It just needs to help people understand what you offer, find the information they need, and know what to do next.

## ⚡ How I Work
**You know your business. I know the web. The best work comes from both.**

- **Talk Directly:** You work directly with the person designing and building your website. There are no middlemen. We discuss the business, structure, and visual direction directly.
- **Built for the Business, Not a Template:** I do not start by picking a template. I start by understanding your business, the people you want to reach, and what the website actually needs to do. Meaning comes first, design follows.
- **Real Performance:** I focus on what actually makes a website fast and usable: lightweight page structure, semantic HTML, automatically optimized images, and JavaScript only where it is genuinely needed.
- **Full Ownership:** Once the project is complete, the website becomes a business asset that you own. The domain stays in your name, the source code is handed over in full, and there are no required monthly subscriptions just to keep it online.

## 🛠️ Technology Stack
Technology should serve the business. I use only as much technology as needed to solve the problem well:
- **Core:** Astro, Svelte 5
- **Styling:** Tailwind CSS v4 (*Strict v4*)
- **Environment:** Node.js, pnpm, Git
- **Architecture:** Lightweight DOM, decoupled data, and accessible interactions.
